# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's **Report a vulnerability** button on the repository's **Security** tab to send a private report. Include the version, steps to reproduce and the potential impact. You can expect an acknowledgement within a few days.

## Scope notes

- All data is stored locally. The desktop app makes no network requests of its own; sync works through a folder you choose.
- The web demo stores its data in your browser's local storage only.
