# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - Unreleased

### Added
- Workspaces, boards, lists and cards with pointer-based drag and drop
- Labels, checklists, attachments, comments, activity log, custom fields
- Recurring cards, dependencies, priorities, due and start dates, time tracking
- Calendar, timeline and milestones
- Configurable home dashboard, quick capture inbox, focus timer
- Saved filters, global search, archived cards screen, right-click menus
- Card templates, board duplication, Markdown board export
- JSON export/import, automatic and manual backups with restore
- Folder-based sync and daily desktop notifications
- Dark and light themes with a custom accent colour
- Web demo (runs entirely in the browser) and Windows installer
